# SINI ORCHESTRATOR v6.0

## Project Overview
This repository contains the Node.js/Express backend server for SINI ORCHESTRATOR v6.0, offering various API endpoints for authentication, license verification, and matrix operations.

## Getting Started
- Clone the repository
- Run `npm install` to install the required dependencies
- Set up your environment variables in a `.env` file
- Start the server using `node src/app.js`
